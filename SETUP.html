StockPro

Système de Gestion de Stock Professionnel

⚠️ Important: Vous devez importer la base de données avant de pouvoir utiliser l'application.

🚀 Installation

1

Créer la base de données

Exécutez la commande suivante dans MySQL:

CREATE DATABASE stockpro CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
2

Importer le schéma

Importez la structure et les données de test:

mysql -u root -p stockpro < backend/sql/database.sql
3

Configurer les paramètres

Éditez backend/php/config.php avec vos identifiants MySQL:

const DB_HOST = 'localhost';
const DB_USER = 'root';
const DB_PASS = 'votre_mot_de_passe';
const DB_NAME = 'stockpro';
4

Accéder à l'application

Cliquez sur le bouton ci-dessous pour accéder à l'interface de connexion:
